# AHJ Atlas 1.8.0 — more evidence, your documents, and saved report notes

This release includes all changes since 1.7.0, giving research and project chat more room to work with evidence.

## What's new

- **Add documents you already have.** In a project's **Sources** tab, use **Add a document you have** for PDFs with a text layer, HTML, or plain-text files up to 50 MB. Text is extracted locally and labeled as your document. Chat can use it in the next reply; choose **Continue research** to include it in research and a new report. Scanned PDFs without text are refused; OCR and Word/Excel imports are not supported.
- **A fallback reader for blocked websites.** Research and chat can use Anthropic's web fetch when the app's reader cannot open a page. Fetched text joins the project's source register and can be cited. This reader runs on Anthropic's servers and cannot run JavaScript.
- **More room for research.** Requests can carry up to 300,000 input tokens, with checkpoint restarts at 200,000. Each research stage can restart from its saved checkpoint four times. Research can use 80 searches, longer page reads up to 60,000 characters, and up to 45 minutes of active time. The evidence check and final report use high reasoning effort, and the final report receives larger source excerpts and stage briefs.
- **More evidence in project chat.** Replies start with larger saved-report, research, source-register, and citable-excerpt packages. Lookups can return up to 60,000 characters, with up to 30 page reads per reply. **Standard** uses Sonnet 5.5 and **Premium** uses Opus 5.5; both use high reasoning effort. Chat uses the model's available context and output allowance instead of separate app token ceilings.
- **Save chat findings as report notes.** Chat can propose a note for you to apply. Saved notes appear on **Overview** and in PDF, Excel, and JSON exports, with linked source citations and a label identifying their origin. They survive report rebuilds and can be removed. They are kept separately from research findings and are not re-verified by research.
- Page reading preserves more links and table columns. US searches receive the project's city and state when available. Evidence excerpts prioritize relevant passages and then use the remaining space for other source text.

## Costs and limitations

Larger contexts, longer reads, higher reasoning effort, and additional searches can increase Anthropic usage. The app does not enforce spending limits; your Anthropic invoice is authoritative. Adding a document or applying a saved note does not start a paid request by itself.

Research and chat still require professional review. A citation, matching quotation, or model review does not establish code compliance, legal applicability, or completeness. Saved report notes are user-approved chat findings, not independently verified research.

Web fetch cannot execute JavaScript, and its text cap does not apply to whole PDFs. Live-provider behavior for the expanded web-fetch requests has not yet been verified in the documented checks; automated coverage uses synthetic responses.

## Updating and Windows installation

From 1.7.0, use **API & spending → App updates → Check for updates**, then **Download update** and **Restart and install** after this release is published. Earlier versions require a manual installation. Back up your workspace before upgrading and use the same Windows account to keep saved projects and the remembered credential.

For a manual installation, download `AHJ-Atlas-1.8.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. The installer includes the app runtime. The optional JavaScript page renderer uses an installed Edge or Chrome browser.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections. A matching checksum confirms the published bytes; it does not prove the publisher's identity.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

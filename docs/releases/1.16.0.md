# AHJ Atlas 1.16.0 — A guided practice tour, desktop menus, and chat context usage

This release includes changes since 1.15.0.

## What's new

- **Explore Atlas with a guided tour.** Choose **Guided tour** in the top bar or **Help → Take the guided tour** in the desktop app. Seven chapters walk through the workspace, project setup, reports, sources, research controls and chat using Sampleton, a fictional practice project. The tour can resume after a reload or start at a chosen chapter from the User guide. Ending it restores your project, draft and chat panel, including when you leave during the practice form.
- **Use Atlas commands from the desktop menu.** File, View and Help menus provide new research, address exports, API and spending settings, report tabs, chat, the tour, help, diagnostics, updates and About. Keyboard shortcuts include **Ctrl+N** for new research, **Ctrl+1–5** for report tabs, **Ctrl+J** for chat and **F1** for the User guide. Zoom, full screen and reload are also available.
- **See how much context a chat reply uses.** A gauge below the chat cost shows the latest request's counted input against the model's context window, updating during a reply. Finished replies retain their own context figures. Tooltips explain exact counts, growth during lookups and earlier messages left out of the request. The gauge turns amber near the input limit and red when a request does not fit. It uses the token counts Atlas already performs and adds no API requests or charges.

## Limitations

The tour's project, sources and recorded chat are fictional examples. They are held separately from your saved projects, excluded from exports and spending, and never sent for research. Research and chat controls are held while the tour runs; end the tour to return to your own work. The tour does not validate real research results.

Context figures describe individual counted requests, not remaining spending or a guarantee that the full conversation is included. Older replies may have no figure. Findings, citations and chat replies require professional review and do not establish code compliance, legal applicability or completeness. API costs remain estimates; your Anthropic invoice is authoritative.

## Updating and Windows installation

From 1.7.0 or later, use **API & spending → App updates → Check for updates**, then **Download update** and **Restart and install** after this release is published. Earlier versions require a manual installation. Back up your workspace before upgrading and use the same Windows account to keep saved projects and the remembered credential.

For a manual installation, download `AHJ-Atlas-1.16.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. The installer includes the app runtime. The optional JavaScript page renderer uses an installed Edge or Chrome browser.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections. A matching checksum confirms the published bytes; it does not prove the publisher's identity.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

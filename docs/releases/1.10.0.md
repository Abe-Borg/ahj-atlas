# AHJ Atlas 1.10.0 — more reliable research and chat

This release includes all changes since 1.9.0, improving research recovery, chat context reuse, and the new-project form.

## What's new

- **Keep your new-project draft.** Building use now starts as **Not yet specified**, and your selected use stays visible beside the required fields. Opening another project keeps the filled form in page memory; **New research** restores it. Choosing **New research** again while the form is open asks before clearing it. Reloading the page can still lose the draft.
- **Reuse chat evidence across follow-ups.** Chat keeps its opening evidence snapshot across messages and app restarts, so searches and page reads do not repeatedly rewrite the same large cache prefix. New and changed sources still reach the next reply. Research, changed reports or briefs, and large source updates refresh the snapshot. This can reduce repeated cache-write charges; cache hits are not guaranteed.
- **Keep large research histories responsive.** Scheduling, polling, and project refreshes no longer decode every saved request and response. The full records remain available for diagnostics and review.
- **Finish research with the evidence it just read.** Research stages and the Opus evidence check now try to complete their briefs from the live conversation before using the reserved fresh-context fallback. This helps retain decisive passages from recent tool results while preserving the existing request limits.
- **Limit repeated replay of fetched documents.** Research saves fetched PDFs and large fetched text, then continues from saved findings and bounded excerpts. In chat, a fetched PDF or large fetched-text history ends further lookups and moves toward an answer; repeatedly pending provider turns can stop with **Limit reached**. Saved sources remain available for a follow-up.
- **Recover from interrupted research streams.** When generation has started and the stream drops, the app records an estimated charge and retries research within the existing retry, request, and active-time allowances. Failed drafts and incomplete tool calls are discarded. Chat records the same estimate and ends the failed reply; it does not retry automatically.

## Costs and limitations

An interrupted-stream charge uses partial input, cache and search usage plus an estimate of output from received characters. If usable usage information is missing, the original reservation becomes the recorded estimate. Activity and diagnostics identify these estimates. Hidden thinking, output not received, and later server-tool work can make the estimate differ from the invoice. Automatic research retries can incur additional usage, and failed-stream time counts toward the active-time allowance.

Requests whose outcome is uncertain before generation starts, ambiguous batch submissions, and previously saved unknown attempts still require the existing reconciliation steps. The app does not enforce spending limits; your Anthropic invoice is authoritative.

Document replay limits do not cap the initial fetched PDF size or provider charges. Automated checks use synthetic providers; live cache behavior and provider continuation behavior remain unverified in the documented checks. Findings, citations, and exported reports still require professional review and do not establish code compliance, legal applicability, or completeness.

## Updating and Windows installation

From 1.7.0 or later, use **API & spending → App updates → Check for updates**, then **Download update** and **Restart and install** after this release is published. Earlier versions require a manual installation. Back up your workspace before upgrading and use the same Windows account to keep saved projects and the remembered credential.

For a manual installation, download `AHJ-Atlas-1.10.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. The installer includes the app runtime. The optional JavaScript page renderer uses an installed Edge or Chrome browser.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections. A matching checksum confirms the published bytes; it does not prove the publisher's identity.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

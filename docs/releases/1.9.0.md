# AHJ Atlas 1.9.0 — Ask Atlas, essentials exports, and clearer project tracking

This release includes all changes since 1.8.0: project renaming, resource-limit diagnostics, question closure tracking, a smaller Excel export, and a direct way to ask Atlas about an unresolved question.

## What's new

- **Ask Atlas about a question.** Choose **Ask Atlas** on a **Questions to resolve** card to send that question through **Chat with Atlas**, using the reply depth selected there. Atlas starts with the project's saved evidence and can research public sources when needed. Its reply appears in the conversation; a proposed answer is saved only when you choose **Apply**. The former **Chat with AI** tab is now named **Chat with Atlas**.
- **Export an essentials workbook.** Choose **Export → Excel essentials** for the report's findings, contacts, authorities, submission requirements, questions, notes, and source register. It keeps evidence references and question statuses while omitting source excerpts, processing mode, and estimated API costs. Once a report exists, it also omits research briefs; incomplete projects retain those briefs. **Excel workbook** remains available for the full export.
- **Rename a project after research starts.** Edit **Project name** and choose **Save name**. The saved name appears in the sidebar, project header, chat, Activity, and exports. Saving it does not stop running research, restart a stage, or rewrite saved findings. Project-list refreshes preserve the newest saved name.
- **See why a question was closed.** When a later report omits an open question, it is saved as **Closed** with the reason **A later research report no longer includes this question.** Answered, dismissed, and closed questions remain available below the open cards, and reasons appear in Activity and exports. Answers or dismissals saved while the new report is being applied are preserved. A closure alone does not prompt another research round.
- **Identify research limits in diagnostics.** Detailed events record when research reaches a request, context, search, read, time, or other resource allowance, including whether work stopped, a lookup was refused, or evidence was clipped. These events help explain incomplete research and apply to research rather than project-chat allowances.

## Costs and limitations

**Ask Atlas** starts a chat request and can incur Anthropic usage, including searches and page reads. It uses the existing chat tools and allowances. Renaming, exporting, and applying a proposed answer do not themselves start paid research; **Research with saved answers** starts a separate research round. The app does not enforce spending limits; your Anthropic invoice is authoritative.

A closed question means the later report omitted it, not that the issue has been independently resolved. Answers saved from chat remain user-approved context. Findings, citations, and exported reports still require professional review and do not establish code compliance, legal applicability, or completeness.

## Updating and Windows installation

From 1.7.0 or later, use **API & spending → App updates → Check for updates**, then **Download update** and **Restart and install** after this release is published. Earlier versions require a manual installation. Back up your workspace before upgrading and use the same Windows account to keep saved projects and the remembered credential.

For a manual installation, download `AHJ-Atlas-1.9.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. The installer includes the app runtime. The optional JavaScript page renderer uses an installed Edge or Chrome browser.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections. A matching checksum confirms the published bytes; it does not prove the publisher's identity.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

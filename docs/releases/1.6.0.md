# AHJ Atlas 1.6.0 — project chat and evidence you can inspect

This release includes all changes since 1.5.2, including the new **Why trust it?** topic and detailed dossier in the app footer and User guide. They explain source provenance, automated work, data destinations, model settings, costs, limits, and practical ways to check the app's findings.

## What's new

- Research uses Claude Sonnet 5.5 and Opus 5.5, with capability checks before requests. Saved research conversations can retain their original model until rebuilt.
- Project chat has Standard, Deep, and Opus reply depths, more saved project context, live streamed replies, Markdown formatting, public web research, and citations. Pages read in chat join the project's source register; search results remain discovery leads.
- Chat can propose answers, question dismissals, research rounds, and location corrections as cards. Proposed edits wait for **Apply**; research and location cards start paid research. Chat replies already incur charges and can add sources before a card is applied.
- A declined chat reply is clearly labeled and offers a user-initiated retry with the other model. Retrying after a lost local response reuses the submission identifier to avoid duplicate replies.
- The continuation dialog can correct the address or site description while retaining sources, previous findings, and recorded costs. Address matching handles more languages and US country spellings.
- Building use is a dropdown, defaulting to Hyperscale data center, with a validated custom option. **About** shows the version, author information, and license; the installer asks users to accept the license.
- Connection status reflects a missing or rejected key. Research progress notes are preserved through recovery, while progress and location text are excluded from diagnostic downloads.

## Costs and review

**The app no longer enforces spending limits.** It shows recorded and pending cost estimates for research and chat. Work and time allowances are not dollar caps; use your workspace spend limit in Anthropic Console if you need a hard cap. Chat uses real-time pricing even for batch projects. Your Anthropic invoice is authoritative.

Findings still require professional review. A matching quotation or model review does not establish code compliance, legal applicability, or completeness. Approved chat suggestions become user context, not independent source evidence. Use **Why trust it?** to inspect the mechanisms and their limits.

Back up your workspace before upgrading. Install under the same Windows account to retain saved projects and the remembered credential. Existing projects stopped at a former spending limit wait for an explicit continuation; they do not automatically restart because the limit was removed.

## Windows installation

Download `AHJ-Atlas-1.6.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. Updates remain manual.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections.

Research and chat require internet access and an Anthropic API key with access to the configured models. Ordinary search and source reading do not require Edge or Chrome; the optional JavaScript page renderer uses an installed Edge or Chrome browser. The installer includes the app runtime.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, upgrades, backup, uninstall, and checksum steps.

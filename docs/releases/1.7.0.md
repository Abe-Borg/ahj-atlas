# AHJ Atlas 1.7.0 — in-app updates and sturdier final reports

This release adds updates from inside the app and fixes a failure where a finished project could stop just before its report. It includes all changes since 1.6.0.

## What's new

- **Update from inside the app.** When a newer release is published, the installed Windows app shows **Download update** in a banner and under **API & spending → App updates**.
  - The app downloads the installer from this project's GitHub Releases and checks its SHA-256 against the release's `SHA256SUMS.txt`, and against GitHub's own asset digest when available. It deletes the file if they differ.
  - **Restart and install** closes the app, upgrades it in place and reopens it on the new version. Your workspace and remembered key are kept.
  - The next launch tells you whether the update finished.
  - Installing waits until no research or chat reply is running.
  - Checking for updates still never downloads or installs anything by itself.
- **Final reports are no longer discarded over a missing summary row.** The final review is asked to write its jurisdiction and coverage rows first. If it still leaves one out, the report is kept:
  - A missing jurisdiction is shown as unverified, with a question to confirm it, so code findings stay conditional.
  - Missing coverage is filled in from what the research stages recorded.
- **Recover a blocked report without paying again.** If a final report was blocked by the app's report checks, **Continue research** or **Finish with saved evidence** first rechecks the saved review response. If it now passes, and nothing about the project or its saved evidence has changed, the report is saved with no new request.
- **Research summaries are no longer lost on a stage's last request.** If a stage's final summary fails the coverage check on its last allowed request, the summary is kept, labeled as unverified leads. The stage shows the exact reason.
- Diagnostics now name the report section that failed a check, report rows that were rebuilt, and report recoveries.

## Updating from 1.6.0

1.6.0 cannot update itself, so install 1.7.0 manually one time, using the steps below. From 1.7.0 onward, later releases can be installed with **Download update** and **Restart and install**.

After upgrading, a project that 1.6.0 left in **Needs attention** because its final report was rejected can use **Continue research**. The app rechecks the saved report before starting a new paid review.

## Costs and review

The app does not enforce spending limits. Recovering a saved report makes no request. A new review, when one is needed, is billed as before. Your Anthropic invoice is authoritative.

Findings still require professional review. A rebuilt or recovered report keeps the same evidence checks. A matching quotation or model review does not establish code compliance, legal applicability, or completeness.

A matching SHA-256 shows that the installer is the one published in the GitHub Release. It does not prove who built it, because the installer is unsigned. Back up your workspace before any upgrade.

## Windows installation

Download `AHJ-Atlas-1.7.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. Install under the same Windows account to keep saved projects and the remembered credential.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections.

Research and chat require internet access and an Anthropic API key with access to the configured models. Ordinary search and source reading do not require Edge or Chrome; the optional JavaScript page renderer uses an installed Edge or Chrome browser. The installer includes the app runtime.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

# AHJ Atlas 1.5.2 — update checks

Installed Windows builds now check GitHub Releases for a newer published version when opened and once every 24 hours while running. A notice appears when a newer Windows installer is available. You can also use **API & spending → App updates → Check for updates** at any time.

The app opens the release page so you can download the installer and `SHA256SUMS.txt`, verify the checksum, close AHJ Atlas, and install the update. It does not download or install updates automatically. Checks need internet access; a failed check can be retried with the button.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm that the download comes from this project's GitHub Release and verify its SHA-256 checksum before choosing whether to run it. Do not disable Windows security protections.

Research and chat still require internet access and an Anthropic API key. See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, upgrades, backup, uninstall, and checksum steps.

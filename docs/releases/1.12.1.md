# AHJ Atlas 1.12.1 — Research recovery and standards coverage

This patch includes all changes since 1.12.0, improving research completion, saved progress, long-document reading, and cost estimates.

## What's fixed

- **Complete standards checklists with Canadian and other standards.** Research now accepts individual CAN/ULC, CSA, UL, and FM designations alongside NFPA targets, including labelled NFPA rows. Grouped or mixed designations remain rejected, with an error naming the rows to fix. If a final report omits a non-NFPA checklist standard and no saved answer covers it, the report adds a question to confirm its applicability and adopted edition.
- **Keep useful progress when one quotation is inexact.** A progress save retains its brief, questions, and exact source-linked claims. Inexact claims become **Unverified lead** questions and do not count as evidence.
- **Avoid repeated requests to blocked pages.** Source-reading refusals with HTTP 401, 403, 406, or 429 are remembered for 15 minutes. The error suggests JavaScript rendering or web fetch as another way to read the source.
- **Search and read longer PDFs.** Searches cover up to 400 pages per call and identify where to continue. Reads and searches can start through page 5,000, and repeated searches reuse extracted text while the five-minute document cache remains available.
- **Account for unitemized cache writes.** When provider usage reports more cache-creation tokens than its duration breakdown, estimates price the remainder as five-minute writes. Existing recorded costs remain unchanged.

## Limitations

These fixes do not automatically rerun earlier research or rewrite existing reports. Research allowances and source-access restrictions still apply. An unverified lead is a question to investigate, not a verified finding. Costs remain estimates; your Anthropic invoice is authoritative. Automated regression checks use synthetic providers and do not establish live model access or research accuracy.

Findings, citations, and exported reports require professional review and do not establish code compliance, legal applicability, or completeness.

## Updating and Windows installation

From 1.7.0 or later, use **API & spending → App updates → Check for updates**, then **Download update** and **Restart and install** after this release is published. Earlier versions require a manual installation. Back up your workspace before upgrading and use the same Windows account to keep saved projects and the remembered credential.

For a manual installation, download `AHJ-Atlas-1.12.1-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. The installer includes the app runtime. The optional JavaScript page renderer uses an installed Edge or Chrome browser.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections. A matching checksum confirms the published bytes; it does not prove the publisher's identity.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

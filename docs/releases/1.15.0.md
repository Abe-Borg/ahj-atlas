# AHJ Atlas 1.15.0 — Word and Excel documents, web-aware chat, and update details

This release includes changes since 1.14.0.

## What's new

- **Attach Word and Excel files.** Add `.docx` and `.xlsx` files in Sources or chat alongside PDF, CSV and text files. Atlas reads these files locally, including Word headers, notes and tables, and Excel sheets, dates and saved formula results. Hidden sheets are labeled. Older `.doc` and `.xls` files and password-protected documents are not supported. The file pickers now list supported formats only.
- **Chat can check the web as needed.** Atlas uses project records first and can search and read public pages to check current or missing information. Each finished reply indicates whether it used the web and how many searches and pages it read. Copy an answer or copy a table for use in a spreadsheet or document.
- **See update details.** App updates shows the published release notes, date and installer size, and the verified checksum after download. When restarting to install, the installer presents its license agreement and installation pages; canceling leaves the current version installed.
- **Updated AI services.** Research and chat use updated web tools that can filter results. If an eligible real-time request is declined, it may fall back to another model; the app identifies the answering model and estimates each model's cost. Dynamic web filtering is not eligible for zero data retention. Economy chat is retired for new messages; existing replies and their recorded costs remain available. Standard and Premium remain available.

## Limitations

Document extraction is text-based and may not preserve all layout or formatting. Excel uses saved formula results; unsupported number formats may be shown as stored values. Review extracted information against the original files. Web results, findings, citations, and chat replies require professional review and do not establish code compliance, legal applicability, or completeness. API costs remain estimates; your Anthropic invoice is authoritative.

## Updating and Windows installation

From 1.7.0 or later, use **API & spending → App updates → Check for updates**, then **Download update** and **Restart and install** after this release is published. Earlier versions require a manual installation. Back up your workspace before upgrading and use the same Windows account to keep saved projects and the remembered credential.

For a manual installation, download `AHJ-Atlas-1.15.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. The installer includes the app runtime. The optional JavaScript page renderer uses an installed Edge or Chrome browser.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections. A matching checksum confirms the published bytes; it does not prove the publisher's identity.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

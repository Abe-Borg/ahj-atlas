# AHJ Atlas 1.5.1 — unsigned Windows x64 installer

This release provides a per-user Windows x64 desktop installer. The installed app includes its runtime, opens in its own window, and keeps projects and the remembered credential in the current user's application-data folder across upgrades and a normal uninstall.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm that the download comes from this project's GitHub Release and verify its SHA-256 checksum before choosing whether to run it. Do not disable Windows security protections.

Research and chat require internet access and an Anthropic API key. Ordinary search and source reading do not require Edge or Chrome. The optional JavaScript page renderer currently uses an installed Edge or Chrome browser.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, upgrades, backup, uninstall, and checksum steps.

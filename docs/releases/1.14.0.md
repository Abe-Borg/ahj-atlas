# AHJ Atlas 1.14.0 — Chat images, a floating chat panel, and address exports

This release includes all changes since 1.13.0, adding images to chat, keeping chat beside your report, and exporting the addresses of selected projects.

## What's new

- **Send images to Chat with Atlas.** Choose **Attach image**, paste a screenshot into the message box, or drop image files on it. Each message can carry up to five PNG, JPEG, GIF or WebP images, up to 20 MB each, alongside up to five documents. Atlas resizes and re-encodes images locally, applies a phone photo's orientation, and removes embedded metadata before sending them. Sent images remain with the conversation and open full size from their thumbnails. Follow-up replies can use them while they fit the conversation's history and image allowances. Image processing is local; a chat reply uses the selected model and incurs its usual API cost, including the images.
- **Chat beside the report.** Open **Chat with Atlas** in the project header or from the bottom-right launcher. The floating panel stays open as you move between report tabs and projects. Drag, resize, expand or minimize it; the launcher indicates a reply in progress. Each project's conversation, unsent draft and pending reply stay separate. On narrow windows the panel fills the screen. **Enter** sends a message, **Shift+Enter** starts a new line, and **Escape** minimizes the panel.
- **Export selected project addresses.** Choose **Export addresses** in the sidebar, select projects, and download one CSV or Excel file containing project name, address, country, parcel or site description, and discipline. Filter the checklist to find projects; hidden rows keep their selection and the count shows how many selected projects are hidden. CSV supports accented names and spreadsheet formula protection. The export contains address details, without report findings, sources or costs.

## Limitations

Images attached to chat are user-provided information. They are not added to Sources, included in project exports, or used as research evidence for the report. Attach a supported document through **Attach document** when it should become a project source. Small text or drawing details may lose clarity when an image is resized; review the reply against the original. Older images can fall outside a later reply's history or image allowance.

Unsent chat drafts and attachments remain available while switching projects in the same browser session; saved messages and sent images persist across app restarts. Very large address selections may need to be exported in parts.

Automated checks use synthetic providers. Findings, citations, image interpretations and exported reports require professional review and do not establish code compliance, legal applicability, or completeness. Costs remain estimates; your Anthropic invoice is authoritative.

## Updating and Windows installation

From 1.7.0 or later, use **API & spending → App updates → Check for updates**, then **Download update** and **Restart and install** after this release is published. Earlier versions require a manual installation. Back up your workspace before upgrading and use the same Windows account to keep saved projects and the remembered credential.

For a manual installation, download `AHJ-Atlas-1.14.0-Windows-x64-Setup.exe` and `SHA256SUMS.txt` from this release, verify the SHA-256 checksum, close AHJ Atlas, and run the installer. The installer includes the app runtime. The optional JavaScript page renderer uses an installed Edge or Chrome browser.

The installer and executable are unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Confirm the download comes from this project's GitHub Release and verify its checksum before choosing whether to run it. Do not disable Windows security protections. A matching checksum confirms the published bytes; it does not prove the publisher's identity.

See the [Windows installation guide](https://github.com/Abe-Borg/ahj-atlas/blob/main/docs/windows-installation.md) for installation, in-app updates, backup, uninstall, and checksum steps.

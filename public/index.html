SHARE WITH YOUR TEAM

Export workspace

Save every project in this workspace to one file. A teammate chooses Import workspace in their AHJ Atlas and picks the file to continue where you are.

  • Included: reports, sources and the documents you added, research progress, chat history and images, report notes, answered questions, Activity, and recorded costs.
  • Not included: your API key and diagnostics. Each person connects their own API key.

The file holds the full research record, including addresses, source text and chat. Share it only with people who should see these projects.
